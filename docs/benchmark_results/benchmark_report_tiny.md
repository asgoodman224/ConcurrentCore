## Notes

- Latency in the task scope is measured from submission to the completion callback, so it
  includes queueing delay: all jobs are submitted at once, so later jobs wait for earlier ones.
- Network-scope latency is measured by the client from sending SUBMIT_JOB to receiving
  the JOB_FINISHED event, and also includes the queueing delay.
- Worker counts above the number of logical cores (12) oversubscribe the CPU; no further speedup is expected for CPU-bound work there.
- File workloads read from the OS page cache after the warm-up run, so they measure
  hashing/compression throughput more than raw disk bandwidth.
